# Frontend laboratory 06

This is the exercise starter for [laboratory 06](../../README.md), using Angular 21.

See [Local frontend setup](../../../../FRONTEND_LABS.md) for mock and Java backend startup, credentials, ports, and the manual checklist.

```bash
npm ci
npm start
```

Use `npm start` to load the proxy once you have configured it in lab 06. Run the supplied mock server in a separate terminal; Java and PostgreSQL are optional.

```bash
npm run build
npm test -- --watch=false --browsers=ChromeHeadless
```
